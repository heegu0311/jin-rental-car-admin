# 검색 노출 설정 (2026-11-06)

첨부 SEO 표 기준. 기존 제목·설명·키워드는 유지한다.

- 공개: 홈, 회사소개, 사고대차, 신차, 이용안내, 문의, 일·주·월 렌트, 차량 상세, 이벤트 목록.
- 비노출: 공지 목록/상세, 개인정보 처리방침, 이용약관, 관리자 전체.
- 이벤트 상세는 종료일이 지난 경우 noindex. ISR 갱신(최대 3시간) 또는 관리자 저장 시 반영.
- 공개 사이트 robots는 noindex 페이지의 크롤링을 허용해 검색엔진이 지시를 읽게 한다. API는 크롤링 제외.
- 사이트맵에는 공개 정적 페이지, 공개 차량, 시작했고 종료되지 않은 활성 이벤트만 포함. 조회 실패는 오류로 처리.

검증: 타입 검사 통과, 테스트 18개 통과, lint 오류 없음(web 기존 미사용 변수 경고 1개). 양쪽 빌드는 Google Fonts 네트워크 다운로드 실패로 완료하지 못함.

로컬 main에 커밋. push/배포 및 검색엔진 등록은 수행하지 않음. 실제 검색 반영 여부는 배포 후 재수집이 필요하다.
