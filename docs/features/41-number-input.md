# 숫자 입력 삭제 복구

- 차량 일·주·월 요금, 승차 인원, 자차보험 배기량 구간 상한과 구간별·승합 요금의 빈 입력을 즉시 0/기본값으로 바꾸던 처리를 제거했다.
- 필수 숫자 입력의 편집 중 빈 값은 NaN으로 구분하고 화면에는 빈칸으로 표시한다. 실제 0원은 0으로 표시하며 필수 빈칸은 브라우저 입력 검증에서 저장을 막는다. 차량 요금과 보험 설정의 기존 저장 검증도 빈 숫자를 거부한다.
- 차량 배기량·약정 거리·초과 주행 요금의 선택 입력은 기존 null 처리를 유지한다. 차량 표의 문자열 편집 상태도 이미 빈칸을 유지한다.
- 회귀 테스트: 전체 삭제 → 재입력, 실제 0 표시, 빈 차량/보험 요금과 배기량 상한의 저장 검증.
- admin 테스트 51개, 타입 검사, lint 통과. web 테스트 50개, 타입 검사 통과; lint는 기존 Hero.tsx 미사용 import 경고 1개.
- admin·web 프로덕션 빌드 통과(Google Fonts 다운로드를 허용한 환경에서 재검증). 운영 데이터 저장, 로그인 세션을 사용하는 실제 화면의 1440px/390px 입력 조작은 수행하지 않았다.
- 외부 push·배포 없음. 기존 월렌트 특가·보험 정책 작업은 이 변경의 커밋에서 제외한다.
