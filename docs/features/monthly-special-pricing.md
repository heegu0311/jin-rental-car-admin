# 월렌트 특별가와 적용 기간 — 2026-11-08

- 연결 DB `daerwmqweobyeecbquuh`에 `20261108030243_vehicle_monthly_special_price_period.sql`을 적용했다. 월렌트 특별가(원)와 시작일·종료일을 차량별로 저장한다. 기간은 한국 날짜 기준 양 끝 포함이다.
- 차량 편집 창과 차량 표 편집에서 특가 지정, 특별가, 시작일, 종료일을 수정할 수 있다. 표 편집은 관리자 세션·역할·RLS를 확인하는 서버 동작으로 저장한다. 지정할 때는 특별가와 두 날짜가 모두 필요하다. 기존에 지정만 된 차량은 가격과 기간을 순서대로 채운 뒤 다시 지정할 수 있다.
- 특가 지정이 저장된 차량은 편집 창과 표에서 특별가·시작일·종료일 입력을 잠근다. 안내는 “지정 해제 후 수정하세요.”이다. 지정 해제를 먼저 저장한 다음 값을 고쳐 다시 지정한다. 서버 저장에서도 지정 상태의 가격·기간 변경을 거부한다.
- 특가 지정을 해제해 저장하면 특별 월 요금·시작일·종료일을 한 번에 `null`로 초기화한다. 편집 창과 표에도 비워진 값을 반영한다.
- 특별가는 0원보다 크고 일반 월 요금보다 낮아야 하며 시작일은 종료일 이전이거나 같아야 한다. DB 제약과 서버 입력 검사에 같은 규칙을 적용했다.
- 기존 지정 차량 12대는 새 가격과 날짜가 비어 있어 현재 공개 특가 목록에는 표시되지 않는다. 운영 차량 가격은 변경하지 않았다.
- web과 admin의 `lib/domain/contracts.ts`를 동일하게 유지한다. Git push와 외부 배포는 수행하지 않았다.

검증: 관리자 역할의 DB 트랜잭션에서 정상 가격·기간 저장과 일반 가격 이상 거부를 확인하고 전체 롤백했다. `pnpm test` 53개, 타입 검사, 린트, 빌드를 통과했다. 관리자 로그인 브라우저에서 직접 저장하는 검증은 수행하지 않았다.
